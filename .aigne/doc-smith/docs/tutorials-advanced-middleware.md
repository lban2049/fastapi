# Middleware

Middleware is a function that works with every request before it is processed by any specific *path operation* and also with every response before returning it. It provides a mechanism to run code on a global level for your application, affecting all incoming requests and outgoing responses.

This is useful for implementing cross-cutting concerns such as logging, performance monitoring, authentication, CORS handling, and adding custom headers.

## Creating Custom Middleware

You can create your own middleware using the `@app.middleware("http")` decorator. A middleware function receives the incoming `request` and a function `call_next` that will receive the `request` as a parameter. This `call_next` function passes the request to the next step in the chain, which could be another middleware or the actual *path operation*.

Here's an example that calculates the time taken to process a request and adds it as a custom header `X-Process-Time` to the response.

```python Adding a custom header icon=logos:python
import time

from fastapi import FastAPI, Request

app = FastAPI()


@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start_time = time.perf_counter()
    response = await call_next(request)
    process_time = time.perf_counter() - start_time
    response.headers["X-Process-Time"] = str(process_time)
    return response
```

In this example:
1.  We record the time before processing the request.
2.  We call `await call_next(request)` to pass the request to the corresponding *path operation* and get the response generated by it.
3.  After we have the `response`, we can modify it, like calculating the total process time and adding a custom header.
4.  Finally, we return the modified `response`.

## CORS (Cross-Origin Resource Sharing)

A very common use case for middleware is to handle CORS. Browsers, for security reasons, restrict web pages from making requests to a different domain than the one that served the page. CORS middleware allows you to explicitly permit certain cross-origin requests.

FastAPI provides `CORSMiddleware` to handle this easily.

```python CORSMiddleware example icon=logos:python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware

app = FastAPI()

origins = [
    "http://localhost.tiangolo.com",
    "https://localhost.tiangolo.com",
    "http://localhost",
    "http://localhost:8080",
]

app.add_middleware(
    CORSMiddleware,
    allow_origins=origins,
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.get("/")
async def main():
    return {"message": "Hello World"}
```

You add it to your application using `app.add_middleware()`. The main configuration options are:

*   `allow_origins`: A list of origins that are allowed to make cross-origin requests. You can use `["*"]` to allow all origins.
*   `allow_credentials`: Indicates that cookies should be supported for cross-origin requests.
*   `allow_methods`: A list of HTTP methods that are allowed. You can use `["*"]` to allow all standard methods.
*   `allow_headers`: A list of HTTP request headers that can be supported. You can use `["*"]` to allow all headers.

## Other Included Middleware

FastAPI, through Starlette, provides several other useful middleware components that you can add to your application.

### HTTPSRedirectMiddleware

This middleware enforces that all incoming requests must be either `https` or `wss` (for WebSockets). If an incoming request is `http` or `ws`, it will be redirected to the secure scheme.

```python HTTPSRedirectMiddleware example icon=logos:python
from fastapi import FastAPI
from fastapi.middleware.httpsredirect import HTTPSRedirectMiddleware

app = FastAPI()

app.add_middleware(HTTPSRedirectMiddleware)


@app.get("/")
async def main():
    return {"message": "Hello World"}

```

### GZipMiddleware

`GZipMiddleware` compresses responses for any request that includes `"gzip"` in the `Accept-Encoding` header. This can significantly reduce the size of the data sent to the client, improving performance.

```python GZipMiddleware example icon=logos:python
from fastapi import FastAPI
from fastapi.middleware.gzip import GZipMiddleware

app = FastAPI()

app.add_middleware(GZipMiddleware, minimum_size=1000)

# ... your path operations
```

## Summary

Middleware is a powerful tool for adding common functionality that applies to multiple or all endpoints in your application. You can write your own custom logic or use the pre-built middleware provided by FastAPI and Starlette for tasks like CORS, GZip compression, and HTTPS redirection.
