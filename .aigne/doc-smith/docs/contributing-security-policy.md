# Security Policy

Security is very important for FastAPI and its community. 🔒 This document outlines the security policy, including which versions are supported and how to report a vulnerability.

## Supported Versions

Only the latest version of FastAPI receives security support.

You are encouraged to [write tests for your application](https://fastapi.tiangolo.com/tutorial/testing/) and update your FastAPI version frequently after ensuring that your tests are passing. This practice allows you to benefit from the latest features, bug fixes, and crucial **security fixes**.

For more detailed information on managing your project's dependencies, see the documentation on [FastAPI versions and how to pin and upgrade them](https://fastapi.tiangolo.com/deployment/versions/).

## Reporting a Vulnerability

If you believe you have found a security vulnerability, even if you are not certain, please report it immediately via email to: `security@tiangolo.com`.

When reporting, please be as explicit as possible. Include a detailed description of the issue, all the necessary steps, and example code to reproduce it. The author, [@tiangolo](https://x.com/tiangolo), will thoroughly review your report and get back to you.

## Public Discussions

Please refrain from publicly discussing a potential security vulnerability. 🙊

It is always better to discuss security issues privately first. This approach helps to find a solution and limit the potential impact on the community as much as possible.
