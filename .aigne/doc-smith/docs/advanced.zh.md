# 高级主题

掌握 FastAPI 的基础知识后，你就可以开始探索其更高级的功能，这些功能旨在构建稳健的、生产就绪的应用程序。本节涵盖了超越简单请求和响应处理的重要主题，使你能够管理安全性、使用中间件处理请求、处理实时通信以及构建复杂项目。

以下是你可以深入研究以增强 FastAPI 应用程序的关键领域。

<x-cards data-columns="2">
  <x-card data-title="安全性" data-href="/advanced/security" data-icon="lucide:shield">
    使用 OAuth2、HTTP 基本身份验证和 API 密钥等方案实现身份验证和授权。
  </x-card>
  <x-card data-title="中间件" data-href="/advanced/middleware" data-icon="lucide:layers">
    学习使用和创建中间件来全局处理请求和响应、处理 CORS 以及实现自定义逻辑。
  </x-card>
  <x-card data-title="WebSockets" data-href="/advanced/websockets" data-icon="lucide:arrow-right-left">
    使用 WebSockets 在客户端和服务器之间实现实时双向通信。
  </x-card>
  <x-card data-title="大型应用" data-href="/advanced/bigger-applications" data-icon="lucide:folder-git-2">
    通过将 API 拆分为多个文件和路由，探索构建大型应用的策略。
  </x-card>
  <x-card data-title="测试" data-href="/advanced/testing" data-icon="lucide:beaker">
    为你的应用编写有效的测试，包括针对依赖项和事件处理程序的单元测试和集成测试。
  </x-card>
</x-cards>

这些主题都提供了使用 FastAPI 构建可扩展、安全且可维护的 API 所需的工具和模式。请浏览与你的项目需求最相关的部分。
