# 安全策略

安全对于 FastAPI 及其社区至关重要。🔒 本文档概述了安全策略，包括支持的版本以及如何报告漏洞。

## 支持的版本

只有最新版本的 FastAPI 会获得安全支持。

我们鼓励您[为您的应用程序编写测试](https://fastapi.tiangolo.com/tutorial/testing/)，并在确保测试通过后，频繁更新 FastAPI 版本。这种做法能让您受益于最新的功能、错误修复和关键的**安全修复**。

有关管理项目依赖的更多详细信息，请参阅关于 [FastAPI 版本以及如何锁定和升级它们](https://fastapi.tiangolo.com/deployment/versions/) 的文档。

## 报告漏洞

如果您认为自己发现了安全漏洞，即使您不确定，也请立即通过电子邮件报告至：`security@tiangolo.com`。

报告时，请尽可能详细。请包含问题的详细描述、所有必要的复现步骤以及示例代码。作者 [@tiangolo](https://x.com/tiangolo) 将会仔细审查您的报告并与您联系。

## 公开讨论

请避免公开讨论潜在的安全漏洞。🙊

最好总是先私下讨论安全问题。这种方法有助于找到解决方案，并尽可能地限制对社区的潜在影响。
