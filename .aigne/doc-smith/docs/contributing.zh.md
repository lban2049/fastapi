# 贡献

感谢您有兴趣为 FastAPI 做出贡献！社区贡献是该项目的命脉，参与方式多种多样，从编写代码、改进文档到报告安全问题。本指南概述了项目维护中使用的工具和流程。

有关开发的具体指南，请阅读官方 [Development - Contributing](https://fastapi.tiangolo.com/contributing/) 文档。

## 报告安全漏洞

对于 FastAPI 及其社区而言，安全是重中之重。如果您认为发现了安全漏洞，请按照以下步骤负责任地报告。

**请不要在公共论坛讨论潜在的安全漏洞。** 私下讨论和解决问题以限制任何潜在影响至关重要。

1.  **立即报告**：直接发送电子邮件至 `security@tiangolo.com`。请尽可能详细地描述复现问题的步骤并提供示例代码。
2.  **最新版本**：确保您使用的是 FastAPI 的最新支持版本。我们鼓励您为应用程序编写测试并频繁更新 FastAPI 版本，以受益于最新的功能、错误修复和安全补丁。
3.  **审查**：作者 ([@tiangolo](https://x.com/tiangolo)) 将会全面审查您的报告并与您联系。

非常感谢您为维护 FastAPI 的安全所做的帮助。

## 项目脚本和维护

该项目使用一系列脚本来自动化各种维护任务，包括管理文档、翻译以及生成贡献者和赞助者列表。如果您计划为项目的基础设施做出贡献，了解这些脚本会很有帮助。

### 文档管理

文档网站通过 `scripts/docs.py` 文件中的一组命令进行管理。这些工具有助于创建新的语言翻译、构建网站并在本地运行以进行开发。

以下是一些关键命令：

| 命令 | 描述 |
|---|---|
| `new-lang <LANG>` | 为指定语言初始化一个新的文档翻译目录。 |
| `build-lang <LANG>` | 构建单一语言的文档。 |
| `build-all` | 构建所有可用语言的文档。最终的网站会放置在 `./site/` 目录中。 |
| `live <LANG>` | 为开发提供特定语言的文档并支持实时重新加载。默认为 `en`。 |
| `serve` | 运行一个简单的服务器来预览包含所有翻译的完整构建网站。您必须先运行 `build-all`。 |
| `verify-docs` | 运行一系列检查，以确保 README、配置和翻译文件有效且为最新。 |

### 自动化翻译

该项目利用自动化来帮助创建和更新文档翻译。`scripts/translate.py` 脚本使用 AI 生成初始翻译，并在源英文内容发生变化时更新现有翻译。

主要命令包括：

| 命令 | 描述 |
|---|---|
| `translate-page` | 将单个英文文档文件翻译为目标语言。 |
| `add-missing <LANG>` | 查找并翻译目标语言中缺失的所有英文文档文件。 |
| `update-outdated <LANG>` | 查找并更新比相应英文源文件旧的翻译。 |
| `update-and-add <LANG>` | 一个方便的命令，可为一种语言同时运行 `update-outdated` 和 `add-missing`。 |
| `make-pr` | 自动化提交翻译更改并在 GitHub 上创建拉取请求的过程。 |

### 社区数据生成

一些脚本可自动化生成用于在文档中鸣谢社区成员的数据文件。这些脚本会查询 GitHub GraphQL API 以获取最新信息。

- **贡献者 (`scripts/contributors.py`)**：通过分析拉取请求，生成代码贡献者、翻译者和翻译审校者的列表。
- **赞助者 (`scripts/sponsors.py`)**：获取 GitHub 赞助者列表以保持赞助者数据为最新。
- **专家 (`scripts/people.py`)**：通过分析 GitHub Discussions 中的活动（尤其是在问答类别中）来识别社区专家。

这些自动化流程确保了贡献得到一致且准确的认可。
