# Tutorials - User Guide

Welcome to the FastAPI tutorials! This user guide is designed to take you from the absolute basics to more advanced topics in a logical, step-by-step manner. Each section builds upon the last, providing you with the core concepts and practical examples needed to build robust and high-performance APIs.

Whether you are a beginner or an experienced developer, these tutorials will help you master FastAPI's features efficiently.

  </x-card>
  <x-card data-title="Path and Query Parameters" data-icon="lucide:at-sign" data-href="/tutorials/path-and-query-parameters">

  </x-card>

  </x-card>
  <x-card data-title="Dependencies and Security" data-icon="lucide:shield" data-href="/tutorials/dependencies-and-security">
    Dive into FastAPI's powerful Dependency Injection system to handle shared logic, and learn how to secure your endpoints with authentication schemes like OAuth2.
  </x-card>
  <x-card data-title="Advanced User Guide" data-icon="lucide:graduation-cap" data-href="/tutorials/advanced">

By following these guides, you'll gain a strong understanding of how to leverage FastAPI's features to build modern web APIs. When you're ready, start with [First Steps](./tutorials-first-steps.md) to begin building.
