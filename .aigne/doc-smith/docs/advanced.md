# Advanced Topics

Once you have mastered the basics of FastAPI, you are ready to explore its more advanced features designed for building robust, production-ready applications. This section covers essential topics that go beyond simple request and response handling, enabling you to manage security, process requests with middleware, handle real-time communication, and structure complex projects.

Below are the key areas you can dive into to enhance your FastAPI applications.

  <x-card data-title="Security" data-href="/advanced/security" data-icon="lucide:shield">
    Implement authentication and authorization using schemes like OAuth2, HTTP Basic Auth, and API Keys.
  </x-card>
  <x-card data-title="Middleware" data-href="/advanced/middleware" data-icon="lucide:layers">
    Learn to use and create middleware to process requests and responses globally, handle CORS, and implement custom logic.
  </x-card>
  <x-card data-title="WebSockets" data-href="/advanced/websockets" data-icon="lucide:arrow-right-left">
    Enable real-time, bidirectional communication between clients and your server using WebSockets.
  </x-card>
  <x-card data-title="Bigger Applications" data-href="/advanced/bigger-applications" data-icon="lucide:folder-git-2">
    Discover strategies for structuring large applications by splitting your API into multiple files and routers.
  </x-card>
  <x-card data-title="Testing" data-href="/advanced/testing" data-icon="lucide:beaker">
    Write effective tests for your application, including unit and integration tests for dependencies and event handlers.
  </x-card>
</x-cards>

Each of these topics provides the tools and patterns necessary to build scalable, secure, and maintainable APIs with FastAPI. Explore the sections that are most relevant to your project's needs.
